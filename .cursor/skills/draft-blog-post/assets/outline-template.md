# 見出し草案

`title` は別フィールド。ここにページタイトルを書かない。セクション見出しは h1。

```html
<!-- 導入（見出しなし） -->
<p>こんにちは。なかあつです。</p>
<p>今回は…を購入しましたので開封＆使用感のレビューをしていきます。</p>

<h1>概要</h1>
<p>…</p>

<h1>スペック、特徴</h1>
<ul>
  <li>…</li>
</ul>

<h1>開封</h1>
<p>それでは早速開封していきます。</p>

<h1>使用感</h1>
<p>…</p>

<h1>まとめ</h1>
<p>…おすすめです。</p>
<p>気になっている方はぜひ購入を検討してみてください。</p>
```

比較レビューでは「開封」のあとに「（旧モデル名）との比較」を足す。
フィギュアは「概要 / スペック」を「箱・内容物 / 本体」に差し替える。
不要な見出しは削る。空セクションを残さない。
