# 口調の正本

microCMS の `blogs` から `microcms_get_content` で読む。公開サイトなら `/blog/{id}`。

執筆のたびに全件は読まない。種類が近いものを 1〜2 本選ぶ。

| contentId | 種類 | 見るところ |
| --- | --- | --- |
| `iplay-80-mini-ultra` | 比較レビュー（ガジェット） | 導入、本文 H1、旧モデル比較、まとめ |
| `iplay-70-mini-ultra` | ガジェットレビュー | 購入理由、ゲーム用途の使用感 |
| `airpods-pro-3` | 開封 + アクセサリ | 開封のテンポ、ANC の所感、ケース紹介の足し方 |
| `nothing-headphone-1` | スペック多めの開封 | 概要→スペック→開封→音、後追い追記の入れ方 |

フィギュア・グッズは正本 ID をここに固定していない。`microcms_get_list` でカテゴリ「フィギュア」「グッズ」「生活雑貨」の新しい 1 本を正本にする。

類似記事の足し方:

- 同じメーカー・シリーズの前回（例: iPlay 70 の次が 80）
- 同じカテゴリの直近 1 本（カテゴリ推定の確認用）
