# 構成パターン

本文のセクション見出しは **h1**。サブだけ h2/h3。ページタイトル用の H1 は `title` フィールド側なので、本文先頭にタイトルを繰り返さない。

## ガジェット / 開封レビュー

1. 挨拶 + 導入（何を買ったか、なぜ今）
2. メーカー or 製品の概要（初出メーカーなら「〜とは」）
3. スペック・新機能（箇条書き → 差分の所感）
4. 開封（箱 → 内容物 → 本体。写真セクション）
5. 使用感（目的の用途でどうだったか）
6. 関連アクセサリがあればその後
7. まとめ（所感、誰向けか、検討の一文）

実例: `airpods-pro-3`, `nothing-headphone-1`

## 比較レビュー

開封レビューに加え、旧モデルとの並記を本体セクションに入れる。

- 導入で旧モデルを使う理由と乗り換え理由
- 「（旧）との比較」を h1 か h2 にする
- 差分は外観・ボタン位置・スペック表的な箇条書きのあと、体感

実例: `iplay-80-mini-ultra`

## フィギュア / グッズ開封

1. 挨拶 + 導入（作品名、メーカー、スケール）
2. 開封（箱絵、内容物）
3. 本体（塗装、プロポーション、可動、付属）
4. サイズ感・飾る場所があれば
5. まとめ

タイトルは `【メーカー】製品名【開封レビュー】` が多い。

## ベストバイ / まとめ記事

1. 挨拶 + その年・テーマの導入
2. 項目ごとに h1（製品名）
3. 各項目は短く「なぜ買ってよかったか」
4. 全体のまとめ

## 共通

- 導入のあとにいきなりまとめへ飛ばない
- 写真が多い開封は、短いキャプション文を画像の前後に置く
- 通販リンクは導入直後か末尾。本文中に何度も同じ CTA を置かない
